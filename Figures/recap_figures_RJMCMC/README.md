The results stored in the `Old/` folder are from the analysis of our data prior incorporating the systematic revision of Rasia (2026) and the taxa from the AMD-45 locality (Arnal et al. 2026).

The Figures stored in the `AMD-45/ folder are from the analysis of the data without incorporating the changes of Rasia (2026). However, taxa from AMD-45 were added.

The Figures stored in the `New/` folder are the one obtained from the analysis of the most up-to-date dataset.
